# Agriculture Farming Quiz Discord Bot

Discord bot running daily agricultural knowledge quizzes and farming trivia for farming communities and agtech Discord servers. Commands include /quiz for random multiple-choice questions on soil science, crop rotation, pest identification, irrigation, animal husbandry, and market pricing. /leaderboard shows top scorers, /daily triggers a scheduled daily question, /explain provides detailed explanations for recent quiz answers, /season for current planting calendar by region, and /almanac for growing conditions and harvest timing. Supports configurable difficulty levels, custom question sets via CSV upload, and weekly quiz tournaments with role rewards. Self-hostable, Discord.py, Docker-ready, MIT license.

## Setup
1. Set `TELEGRAM_BOT_TOKEN` in `.env`
2. `pip install -r requirements.txt`
3. `python main.py`
